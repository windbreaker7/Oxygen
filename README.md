**OXYGEN | V2** is a feature-rich, high-performance visual utility and weapon modifier script built on the **Iris UI Engine**. Designed for low overhead and maximum scannability, it features multi-tier ESP systems, real-time tactical radar, and dynamic recoil tuning.

---

## 🚀 Quick Start
To run the latest version of the script directly, execute the following loader:

```lua
loadstring(game:HttpGet("[https://raw.githubusercontent.com/windbreaker7/Oxygen/refs/heads/main/Imgui_Wannabe.lua](https://raw.githubusercontent.com/windbreaker7/Oxygen/refs/heads/main/Imgui_Wannabe.lua)"))()
```

## ✨ Key Features

### 👁️ Comprehensive Visuals (ESP)
* **Player ESP:** Render Bounding Boxes, Tracing Lines, Display Names, Distance, Dynamic Health Bars, and Viewmodel Skeleton Tracking.
* **2D Tactical Radar:** Fully customizable top-down radar with adjustable size, distance scaling, border controls, and team filters.
* **World & Equipment ESP:** Real-time distance tracking and labels for:
  * Active Guns & Viewmodel Loadouts
  * Anti-Personnel Tools
  * Thrown Grenades (Frags & Stuns)
  * Map Surveillance Cameras
  * Planted Defusers
  * Drones & Claymores

### 🔫 Weapon Modifications
* **Dynamic Recoil Control:** Real-time multipliers for horizontal ($X$) and vertical ($Y$) recoil reduction.
* **Parallel Luau Hook:** Integrated external actor hook for complete recoil elimination.

### 🎨 Iris UI Engine & Customization
* **ImGui-Inspired Design:** Clean, multi-tab layout with real-time FPS and Ping performance monitoring.
* **Workspace Asset Support:** Automatic support for custom window background images (`background.jpeg`) via `getcustomasset`/`isfile`.
